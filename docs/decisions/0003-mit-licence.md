# 0003. MIT licence

- **Status:** Accepted
- **Date:** 2026-11-15

## Context

The owner wants anyone to be able to copy, use and change the project freely.

## Decision

License the project under MIT.

## Why

Widely understood, permissive, compatible with nearly everything. The only condition is keeping the copyright notice.

## Consequences

Code from GPL projects (TLP, TuneD, auto-cpufreq, power-profiles-daemon) must not be copied in. Others may build closed products on it.

## Alternatives considered

0BSD or Unlicense (no conditions at all). Apache 2.0 (adds a patent grant). GPL (keeps derivatives open, but restricts reuse).
