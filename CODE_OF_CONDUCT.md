# Code of Conduct

Dynamis Power welcomes everyone, whatever their experience with Linux or programming. Beginners asking questions are as valued as experts writing code.

## Expected behaviour

- Be kind and patient, especially with newcomers.
- Assume good intent, and ask before assuming.
- Give criticism about code and ideas, never about people.
- Accept feedback gracefully, and credit others' work.

## Not acceptable

- Harassment, insults, or personal or political attacks.
- Discriminatory language or imagery.
- Publishing anyone's private information without permission.
- Sustained disruption of discussions.

## Enforcement

Report problems to the maintainer privately through the contact listed on the maintainer's GitHub profile. Reports are handled confidentially. The maintainer may remove comments, code or issues, and may block people who break these rules.

This code applies in all project spaces: issues, pull requests, discussions, and any community channels the project runs.
